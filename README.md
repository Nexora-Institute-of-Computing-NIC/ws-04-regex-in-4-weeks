# Regex in 4 Weeks

**Category:** Workshop - **Duration:** 4 sessions, ~8 hours total - **Sessions:** 4

> **Status:** Scaffolded. Content in progress.

## What you will learn

Read, write, and debug regular expressions with confidence.

## Who this is for

Anyone who has copied regex from Stack Overflow and wished they understood it.

## Sessions

- [Session 1](sessions/session-01.md) - Literals, character classes, and anchors
- [Session 2](sessions/session-02.md) - Quantifiers, groups, and alternation
- [Session 3](sessions/session-03.md) - Lookahead, lookbehind, and backreferences
- [Session 4](sessions/session-04.md) - Performance, security (ReDoS), and real-world patterns

## No prerequisites, no assessments, no credits

Unofficial workshop. Short, self-paced, free. No exam, no grade.
